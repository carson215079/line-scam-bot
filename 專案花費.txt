專案花費明細
================
最後更新：2026-07-16
匯率換算基準：1 USD ≈ 32 TWD


一、開發階段花費（一次性）
----------------------------
| 項目                | 方案         | 費用      | 說明                                   |
|---------------------|--------------|-----------|----------------------------------------|
| Render（運算主機）  | Free         | $0        | 免費方案，閒置會休眠（靠 cron-job 保活）|
| Supabase（資料庫）  | Free         | $0        | 免費無到期限制，500 MB                  |
| cron-job.org（保活）| Free         | $0        | 每 10 分鐘 ping 一次                    |
| LINE Messaging API  | Free         | $0        | 官方免費方案                            |
| GitHub（程式碼）    | Free         | $0        | 公開/私人皆免費                         |
| Anthropic API       | 預付 $5      | 開發測試用| 開發期間測試爬蟲、摘要、問答消耗        |

開發階段總現金支出：約 USD $5（僅 Anthropic API 儲值）
其餘服務全數使用免費方案，無支出。


二、維護階段花費（每月經常性）
--------------------------------
唯一的變動成本是 Anthropic API（依使用量計費），其餘服務維持免費。

Anthropic API 用量估算（Claude Haiku 定價）：
- Input  約 $0.80 / 百萬 token
- Output 約 $4.00 / 百萬 token

固定成本（爬蟲摘要）：
- 每 3 小時爬取、AI 摘要，重複文章會跳過（不重複呼叫）
- 每月約 USD $0.05（幾乎可忽略）

變動成本（用戶問答，最大變數）：
| 用戶規模        | 每日訊息量 | 每月費用(USD) | 每月費用(TWD) |
|-----------------|-----------|---------------|---------------|
| 僅自己測試      | 5–10 則   | $0.10–0.20    | 約 3–6 元     |
| 5 位活躍用戶    | ~25 則    | 約 $2.57      | 約 82 元      |
| 10 位活躍用戶   | ~30 則    | 約 $0.80      | 約 26 元      |
| 50 位活躍用戶   | ~150 則   | 約 $4.00      | 約 128 元     |
| 100 位活躍用戶  | ~300 則   | 約 $8.00      | 約 256 元     |

（註：已設每人每日 30 則上限，防止 API 額度被濫用暴衝）


三、費用控管重點
------------------
1. Anthropic 為「預付制」，餘額用完即停止，不會自動扣款
   （前提：未開啟 Auto-recharge 自動儲值）
2. 查詢餘額：Anthropic Console → Billing
3. 防濫用限額（每人每日 30 則）已上線，避免惡意連發燒光額度
4. 容量保護：DB 達 400MB 自動刪最舊 20% 文章，避免 Supabase 超量


四、結論
----------
- 開發：一次性 USD $5
- 維護：小規模（5 人內）每月約 TWD 3–82 元
- $5 儲值以目前規模可運行數月
- 未來若用戶規模擴大（超過 50 人），再視情況加值即可
